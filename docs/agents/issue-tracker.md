# Issue tracker

Use GitHub Issues in `qu1r0ra/jute-disease-detection` as the repository-native tracker. Pass `--repo qu1r0ra/jute-disease-detection` explicitly to issue commands.

Find the live map and implementation specs by their labels. Use native child issues and blocker relationships. The repository has no canonical native map/spec yet: wait for an approved migration before creating or mutating implementation issues. Configuring this destination does not perform or authorize migration. Keep one canonical queue; do not create a parallel local or external queue.

Claim an issue before work. Record resolution in an issue comment and close only after acceptance. Keep a title-linked map index. Validate draft shape, routing, and relationships before writing; read back exact live state after each successful write. Delete successful temporary drafts.

Pull requests are not the request surface.
