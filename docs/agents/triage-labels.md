# Triage labels

- `needs-triage`: scope and route are not established.
- `needs-info`: required information is missing.
- `ready-for-agent`: scoped work is ready for an agent.
- `ready-for-human`: human judgment or action is required.
- `wontfix`: explicitly declined work.

Use `status:blocked` separately for blocked work. Wayfinder labels distinguish maps from child issues. Verify or set up native labels during an approved tracker migration; do not write labels now or import the old tracker routing taxonomy.
